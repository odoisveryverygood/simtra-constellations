# Towncast demo

Theme: Crafting Constellations. Project name: Towncast.

Open the live city with `?backend=local&port=8088&motion=on`. Confirm the actual population badge. The offline `?demo=1` fixture contains 256 residents and fixed outcomes; use it only as a labelled fallback.

1. Show the moving synthetic population and inspect a resident.
2. Ask a supported prediction question. Explain that responses are simulated, weighted estimates.
3. When the result appears, point out the subtle connections across the existing city: a constellation of perspectives. The lines are illustrative; they do not assert actual social ties.
4. Read the percentages from the result card, inspect a demographic breakdown, then dismiss to return to the city.

Keep the pitch focused: Towncast turns a question into a visible picture of how a synthetic community may respond. The theme lives in the result reveal.

Do not promise real opinions, accuracy against an election, configured persona memory, or real-world prediction accuracy. Live Jev A/B was verified on the local backend on October 10, 2026; remote installations still need their own private provider configuration.
